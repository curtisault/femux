# Key bindings

femux keeps your keys out of the programs you run. Almost everything starts with the prefix,
`ctrl+space` by default: press it, let go, then press one key. Wait a moment after the prefix and
the which-key panel lists the same table as below.

## How the prefix table is laid out

- **Lowercase letters act, or open the list they name.** `s` lists sessions, `w` lists panes,
  `b` opens the side nav and `i` the agent inbox.
- **Shift on a letter means the same thing the other way, its overview, or a new one.** `n` and
  `N` move through tabs, `o` and `O` through floats, `m` sets a mark and `M` lists them, `s` lists
  sessions and `S` starts one, `h` focuses left and `H` grows the pane left.
- **Symbols draw what they do.** `-` splits below and `|` splits right; `[` enters copy mode and
  `]` pastes.
- **Some keys work without the prefix in a mode.** After `prefix space`, sticky normal mode reads
  the prefix table with no prefix until `esc`, `space` or the prefix. Copy mode has its own table.

A few special cases:

- `prefix prefix` sends the prefix key itself to the pane.
- `prefix esc` cancels without doing anything. Any other unbound key after the prefix is
  swallowed and named in the status line.
- `m` and `'` wait for one more letter, `a` to `z`, naming the mark.

## Changing keys

Override any key in `~/.config/femux/config.toml` by action name, then run `femux reload`:

```toml
[input]
prefix = ["ctrl+space", "ctrl+b"]   # more than one prefix is allowed
prefixless_nav = true               # alt+h/j/k/l focus without the prefix

[keys.prefix]
"v" = "split right"

[keys.root]                         # bound with no prefix at all
"ctrl+p" = "palette"

[keys.copy]
"q" = "copy exit"
```

`femux keys list` prints every action name, and `femux keys explain <key>` says what a key does.
Plugin keys only work while that plugin is listed in `[plugins] enabled`.
